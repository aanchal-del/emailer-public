How accurate is this? Emailer is a fast first-pass reviewer, not a final sign-off. Read results by tier:
  • accurate Auto checks — font size, line-height, character counts, fonts, gradients, file size. These are measured from the file, so they're reliable. Only these count toward the score.
  • approximate Observations — CTAs, headlines, columns, spacing, images. Detected by pattern/geometry, so they can occasionally mislabel — review by eye.
  • not checked Manual — GIF weight and real on-device stacking. A static PDF doesn't contain this, so no tool can read it.
  • ai vision Optional AI pass — text baked into images, dark-mode contrast, shadows/blur, overlapping modules. Reads the rendered page rather than the text layer, so it catches what measurement can't. Opt-in per PDF, and it sends your pages to Anthropic. Never scored.
Sections built as flat images can't have their text measured. The score is an indicator, not a guarantee.
